# PDF-генератор заявок на перемещение ТМЦ

CLI-скрипт на Python: превращает табличные данные (CSV из Excel или JSON) в готовый PDF-документ «Заявка на перемещение ТМЦ» — с таблицей товаров, итоговой суммой и блоком подписей.

## Как это работает

1. Заполняете таблицу товаров в Excel и сохраняете как CSV (или используете JSON).
2. Запускаете скрипт — в консоли появляется меню: выбор файла данных и HTML-шаблона.
3. Скрипт автоматически присваивает **номер заявки** и подставляет **дату отгрузки** (день генерации), считает «Итого» по каждой позиции и по заявке.
4. Готовый PDF сохраняется в `output/` и сразу открывается в системной программе.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python generate_pdf.py
```


## Формат данных

**CSV** — кодировка UTF-8 или CP1251 (Excel сохраняет по умолчанию), разделитель `;` или `,`:

```csv
дата приёмки;21.10.2026
товар;количество;цена за шт
винт;30;20
гайка;199;10
```

**JSON:**

```json
{
  "дата приёмки": "23.10.2026",
  "товары": [
    { "товар": "отвёртка", "количество": 12, "цена за шт": 150 }
  ]
}
```

Кодировка и разделитель определяются автоматически — «Сохранить как CSV» в Excel работает без дополнительных настроек.

## Плейсхолдеры шаблона

| Плейсхолдер | Источник |
|---|---|
| `{{ number }}` | номер заявки — автоматически (по счётчику файлов в output/) |
| `{{ ship_date }}` | дата отгрузки — автоматически (день генерации) |
| `{{ receipt_date }}` | дата приёмки — из файла данных |
| `{{ company }}` | юрлицо — константа в скрипте (по умолчанию ООО «Союзинструмент») |
| `{{ rows }}` | строки таблицы товаров — из файла данных |
| `{{ total }}` | итоговая сумма — расчётная (количество × цена) |

Шаблон можно свободно менять: вёрстка — обычный HTML/CSS, кириллица подключается через `@font-face` (шрифт ищется автоматически: папка `fonts/` → системные шрифты Windows/macOS).

## Генерация PDF

Используется [xhtml2pdf](https://github.com/xhtml2pdf/xhtml2pdf) — чистая Python-библиотека, не требует установки системных зависимостей. Скрипт работает на Windows и macOS (на Linux открытие PDF через `xdg-open`).
